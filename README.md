# JEE RUSHER

A mobile-friendly JEE study dashboard prototype.

## Included
- Dashboard
- Daily goals
- Goal completion + local streak calculation
- JEE syllabus tracker for Physics, Chemistry and Mathematics
- Theory / Practice / Revision 1 / Revision 2 tracking
- Calendar with goals and tests
- Test/PDF file selection
- Analytics
- Mistake Book
- Notes
- PWA manifest
- Responsive mobile UI

## Run locally
Open `index.html` in a browser.

## Make it accessible from your phone
Upload the folder to a static host such as Netlify, Vercel, or GitHub Pages. For true multi-device cloud sync, replace localStorage with a backend such as Supabase/Firebase and add authentication.
